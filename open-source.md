I build open-source research software that turns causal and statistical methods into practical tools for measurement and decision-making.

## DeepCausalMMM

[DeepCausalMMM](/deepcausalmmm/) is a Python framework for Marketing Mix Modeling with causal structure learning. It combines temporal deep learning, causal discovery, response-curve modeling, and multi-region analysis to support interpretable marketing measurement and budget optimization.

- [Project details](/deepcausalmmm/)
- [Code](https://github.com/adityapt/deepcausalmmm)
- [JOSS paper](https://doi.org/10.21105/joss.09914)
- [Documentation](https://deepcausalmmm.readthedocs.io/en/latest/)

## CausalGeo

CausalGeo is a Python package for concurrent geo holdouts, bundle lift, and calibrated channel responses. It takes an estimand-first approach: the measured holdout result stays separate from model-assisted channel allocations, and a channel receives no estimate when the design cannot identify it.

- [Project details](/causalgeo/)
- [Code](https://github.com/adityapt/causalgeo)
- [Software record](https://doi.org/10.5281/zenodo.24041239)
